\section{Conclusiones}

\begin{itemize}
    \item Se pudo identificar diversos elementos electrónicos usados en circuitos electrónicos hoy en día, donde se describió su funcionamiento y propiedades, además de su representación gráfica.
    \item Se pudo reconocer la resistencia establecida de fábrica y su tolerancia por medio del código de colores, posteriormente se comprobó este valor con mediciones hechas directamente con el ohmetro, donde el error relativo porcentual de cada resistencia medida no supera el 2\%.
    \item Se abarcaron varias funciones del multímetro, entre ellas, el ohmetro, voltímetro y amperímetro, las cuales se usaron para medir la resistencia de varios de los componentes electrónicos mostrados y el voltaje de una fuente DC, además se usó el medidor de continuidad y su opción para comprobar diodos.
\end{itemize}
