\begin{abstract}
Se identificaron y caracterizaron los principales componentes electrónicos de un 
laboratorio básico (pilas, resistencias, capacitores, bobinas, diodos, transistores,
 relés, fusibles, interruptores, potenciómetros, LEDs, fotorresistencias y un 
 transformador de 110/6 V), determinando el valor nominal de las resistencias 
 mediante código de colores y contrastándolo con el valor medido experimentalmente. 
 Asimismo, se verificó el funcionamiento de un relé y un pulsador NC mediante pruebas 
 de continuidad, se midió el rango de un potenciómetro, se comprobó el comportamiento 
 rectificador de un diodo al invertir su polaridad, y se evaluó la variación de 
 resistencia de una fotorresistencia bajo distintas condiciones de iluminación.
\end{abstract}
