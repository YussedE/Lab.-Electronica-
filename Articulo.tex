\begin{abstract}
Se realizó la identificación y caracterización de los principales 
componentes electrónicos empleados en un laboratorio de electrónica básica,
entre ellos pilas, resistencias, capacitores, bobinas, diodos, transistores,
relés, fusibles, interruptores, potenciómetros, LEDs, fotorresistencias y 
un transformador de 110/6 V. Se determinó el valor nominal de las resistencias 
mediante el código de colores y se comparó con el valor medido experimentalmente 
usando un multímetro digital, calculando el porcentaje de error respecto a
la tolerancia especificada. Adicionalmente, se verificó el funcionamiento
de un relé y un pulsador normalmente cerrado mediante pruebas de continuidad, 
se midió el rango de resistencia de un potenciómetro, se comprobó el comportamiento 
rectificador de un diodo de silicio al invertir su polaridad, y se evaluó 
la variación de resistencia de una fotorresistencia bajo distintas 
condiciones de iluminación.
\end{abstract}
